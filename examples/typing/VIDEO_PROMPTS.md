# TYPING… · image-to-video prompts

Use each JPG in this folder as the START FRAME (already cropped to 16:9 and upscaled to 2560×1440).
Settings for every clip: 16:9 · 1080p (or higher) · 10 s unless noted · no audio · highest quality / "professional" mode.
Name each clip after its image: `s02_ukiyoe.mp4`. For a second take add `_b`: `s00_coldopen_b.mp4`.

Paste this NEGATIVE PROMPT into every clip (if the tool has a negative field):

```
face turning to camera, visible face, extra people, new characters, text, letters, subtitles, watermark, logo, morphing, warping hands, extra fingers, hair changing length or colour, style change, flicker, camera shake
```

Rule for every take: discard it if her face turns to the camera, a new person appears, the hair or sweater changes, objects melt, or text appears. A calm clip with only ambient motion is better than an ambitious warped one.
